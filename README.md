# Grand Mayfair Inn And Suites Private Limited

A responsive, static hospitality and holiday membership website inspired by the business structure of grandsofitelclub.com, with original styling and copy.

## Preview

Serve `dist` with any static web server. No installation or build is needed.

```powershell
python -m http.server 4173 --directory dist
```

Open http://localhost:4173. Run `node verify-site.mjs` for structural and asset checks.

## Included

Responsive navigation, a three-image destination hero, holiday date validation, India/international filters, destination detail dialogs, membership presentation, travel services, planning FAQs, and a holiday brief planner with edit, copy, and download.

## Client content needed

The wordmark, copy, destination ideas, and membership presentation are a first design proposal. Destination photographs are illustrative Unsplash imagery, not photographs of owned or contracted properties. Confirm company branding, authorised stay inventory, membership inclusions and terms, and legal/contact information before a public commercial launch.

The planner creates a brief in the current browser tab; no enquiry is sent, no booking is made, and no payment is taken. Supply the client's email/WhatsApp details and enquiry service to connect real enquiries. No visitor data is stored on a server or in browser storage by this implementation. Fonts load from Google Fonts. Photo attribution and source links are available from the footer.
